SRL Pipeline at a Glance
Semantic Role Labelling (SRL) maps each word in a sentence to its role in an event — who did what, to whom, how, and when. Your code builds this entirely from spaCy's RoBERTa-based parser output across 4 phases and 12 rules.

Phase 1 · Rule 01
Find Predicates
The pipeline starts by scanning every token. A token must satisfy three conditions to become a predicate (the action around which a frame is built): it must be a VERB or AUX, it must be a main verb (ROOT or coordinated conj), and it must not be a bare auxiliary already serving another verb.
Decision flow
1a
Is the token POS = VERB or AUX?
If neither → skip immediately. Only action-class tokens proceed.
1b
Is it a bare auxiliary of another VERB?
If dep ∈ {aux, auxpass, aux:pass} and its head is a VERB → skip. The main VERB handles the frame, not its helper.
1c
Is its dep label in {ROOT, conj}?
Only the sentence root or a coordinated verb qualifies as a main predicate. Everything else (relative clause verbs, etc.) is handled via the nested queue in Rule 10.
✓
Passes → candidate predicate
Sent to Rule 2 (light verb filter) before a frame is created.
Code
extract_srl() · predicate selection loop
for i, (word, pos) in enumerate(zip(words, pos_tags)): # 1a — skip bare auxiliaries that serve another VERB if pos == "AUX" and deprels[i] in ("aux", "auxpass", "aux:pass"): if 0 <= heads[i] < n and pos_tags[heads[i]] == "VERB": continue # 1b — must be VERB or AUX if pos not in ("VERB", "AUX"): continue # 1c — must be ROOT or coordinated verb if deprels[i] not in MAIN_PRED_DEPS: # {"ROOT", "conj"} continue # → candidate predicate — proceed to light-verb filter (Rule 2)

Phase 1 · Rule 02
Skip Light Verbs
Even after passing Rule 1, some verbs are semantically empty — they act as grammatical glue rather than real actions. The lemma of each candidate predicate is checked against a fixed blocklist. If it matches, the predicate is silently dropped and no frame is created.
The blocklist
constant
LIGHT_VERBS = { "be", "is", "are", "was", "were", "am", "been", "being", "note", "include" } lemma = doc[i].lemma_.lower() if lemma in LIGHT_VERBS: continue # drop — no frame created
Example
"The exploit is a buffer overflow that allows code execution."
islemma='be' → in LIGHT_VERBS → dropped
allowslemma='allow' → not in blocklist → frame created ✓
Phase 2 · Rule 03
Assign ARG0 — the Subject
ARG0 answers "who is doing the action?" For active sentences the grammatical subject (nsubj) becomes ARG0. For passive sentences the grammar flips: the grammatical subject becomes ARG1 (the patient), and the by-phrase (the logical agent) becomes ARG0.
Code

Phase 2 · Rule 04
Assign ARG1 / ARG2 — Objects
ARG1 is the direct object — what the action is done to. ARG2 is the indirect object — the recipient or beneficiary. Only the core subtree is used (relative clauses attached to the object are excluded).

Phase 2 · Rule 05
Classify Oblique Args
Prepositional phrases and oblique nominals (dep = obl, nmod, prep) are not simply labelled ARG3. They carry rich semantic distinctions. The classify_obl() function checks four criteria in priority order to assign the right modifier tag.
Priority waterfall
1
NER type = DATE / TIME / DURATION / SET → ARGM-TMP
spaCy's NER overrides everything. "After 2019", "within 24 hours" → TMP.
2
Preposition ∈ MANNER_PREPS → ARGM-MNR
via, by, through, using, with, without → manner of action.
3
Preposition ∈ SPATIAL_PREPS → ARGM-LOC
in, on, at, within, inside, into, onto, upon → spatial location.
4
Word ∈ TEMPORAL_WORDS → ARGM-TMP
after, before, during, while, when — temporal words missed by NER.
✓
Fallback → ARGM-LOC
No other match → default to location. Most unclassified obliques are locative.
Example
"The exploit runs via a crafted HTTP request in the target system."
The exploitnsubj → ARG0
runsROOT
via a crafted HTTP request'via' ∈ MANNER_PREPS → MNR
in the target system'in' ∈ SPATIAL_PREPS → LOC
Phase 2 · Rule 06
Tag Negation
Negation is the simplest rule. If a dependency child of the predicate carries dep = "neg" (words like "not", "never", "no"), that single token is tagged ARGM-NEG. No subtree expansion — it is always exactly one token.

Phase 2 · Rule 07
Tag Adverbials
Adverb modifiers (dep = advmod, npadvmod) describe how or when something happens. The temporal check — same one used in Rule 5 — decides between TMP and MNR. The full subtree of the adverbial is always included.

Phase 2 · Rule 08
Tag Adverbial Clauses
Adverbial clauses (dep = advcl) express subordinate circumstances. Most become ARGM-ADV. Exception: a purpose infinitive ("to execute arbitrary commands") is detected by the presence of a "to" marker and is not tagged here — instead it is pushed onto a nested_queue to become its own separate frame (processed in Rule 10).

Phase 3 · Rule 09
Coordinated Verbs
When two verbs are joined by "and" or "or" (dep = conj, POS = VERB), each gets its own independent frame. The coordinated verb typically has no nsubj child of its own — so the code inherits the subject of the root verb and passes it as ctrl_subject.

Phase 3 · Rule 10
Nested Clauses
Clausal complements — xcomp, ccomp, acl, and purpose advcl — each spawn their own frame via a nested_queue. The key question for each: what is the subject of the nested verb? This is determined by the linguistic notion of "control" — who performs the nested action?
Subject control rules
xcomp
Open clausal complement → object control
The parent's object (or subject if no object) is the controller. "allow the server to run" → "the server" is ARG0 of "run".
ccomp
Closed clausal complement → independent subject
The embedded clause has its own subject — no inheritance. "reports that the module loaded" → "the module" is its own ARG0.
advcl
Purpose infinitive → subject control
The parent's subject is the controller. "the malware attempts to execute" → "the malware" is ARG0 of "execute".
Example
"The malware attempts to exploit a flaw to execute arbitrary commands."

Frame 1 — attempts (ROOT)

The malwarensubj → ARG0
attemptsROOT

Frame 2 — exploit (xcomp)

The malwareinherited from parent subject
exploitxcomp
a flawobj → ARG1

Frame 3 — execute (purpose advcl)

a flawobject of exploit → inherited ARG0
executepurpose inf.
arbitrary commandsobj → ARG1
Phase 4 · Rule 11
Frame Quality Gate
Not all frames produced by Rules 1–10 are useful. A quality gate enforces three conditions before a frame is added to the output. Any frame failing even one condition is discarded.
Three conditions (all must pass)
A
Has at least one non-verb argument
A frame with only a V role is meaningless. There must be at least one ARG0/ARG1/ARGM-* slot.
B
At least one argument span is "meaningful"
Checked by _is_meaningful_span(): any token with NER label, POS=PROPN, all-caps acronym (WMI, RDP, ETW), or non-stop NOUN qualifies.
C
Verb text is non-empty
The V slot must contain actual text. Guards against edge cases from the dependency parser.
Code
_is_meaningful_span() · _is_high_value_frame()
def _is_meaningful_span(text, doc_span_tokens): for tok in doc_span_tokens: if tok.ent_type_: # NER: LSASS, PowerShell return True if tok.pos_ == "PROPN": # proper noun return True if tok.text.isupper() and len(tok.text) >= 2: # WMI, RDP return True if tok.pos_ == "NOUN" and not tok.is_stop: return True return False
Pass vs fail
Fail: "It is used."
DROPPED'it' has no NER, no PROPN, no NOUN → fails condition B
Pass: "PowerShell executes the encoded command."
PowerShellPROPN → meaningful ✓ → frame kept
executesV slot non-empty ✓
the encoded commandNOUN 'command' → meaningful ✓
Phase 4 · Rule 12
Deduplication
Multiple frames for the same sentence can be redundant. After quality filtering, any frame whose non-verb argument word set is a strict subset of an already-accepted frame is discarded. The richer frame (more content) always wins.
Code
_deduplicate_frames()
def _deduplicate_frames(structured): kept, seen_arg_sets = {}, [] for vid, roles in structured.items(): non_verb_vals = frozenset( w.lower() for k, v in roles.items() if k != "V" for w in v.split() ) # drop if this frame's content ⊆ any kept frame is_redundant = any( non_verb_vals <= existing for existing in seen_arg_sets ) if not is_redundant: kept[vid] = roles seen_arg_sets.append(non_verb_vals) return kept

Two frames from the same sentence:
Frame A: {ARG0:'attacker', ARG1:'system', LOC:'network'}kept — richer word set
Frame B: {ARG1:'system'}{'system'} ⊆ Frame A's set → DROPPED
